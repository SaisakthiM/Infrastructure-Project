VAULT·01Secrets
Every value the services need that must never reach the repo, filed by how you get it: API keys you must create at an outside provider, private keys pasted as whole files, and passwords the city issues itself. Stored in the OS keychain, then written into the generated terraform.tfvars files. The browser is never shown a stored value — only whether one exists.

MAINT·02Clean
Remove .terragrunt-cache, .terraform, and generated *.tfvars files that can cause state conflicts.
Options
What gets removed:
.terragrunt-cache/ — Terragrunt module cache (safe to delete, re-downloaded on next deploy)
.terraform/ — Terraform provider plugins (safe to delete, re-downloaded on init)
terraform.tfvars / *.tfvars — Re-generated by social-platform configure --regen
